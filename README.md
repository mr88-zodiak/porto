# Personal Portfolio

A modern personal branding portfolio built with **React** and **Anime.js v4**, featuring smooth scroll animations, a dark theme, and responsive design.

## Sections

- **Home** — Hero with animated intro, skill tags, and CTAs
- **Education** — Timeline-style academic history
- **Projects** — Featured project cards with hover effects
- **Contact** — Contact form and social links

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Customize Your Content

Edit `src/data/portfolio.js` to update:

- Personal info (name, title, email, social links)
- Education history
- Projects
- Skills

## Tech Stack

- React 19 + Vite
- Anime.js v4 (`animate`, `createTimeline`, `stagger`)
- CSS custom properties for theming

## Build for Production

```bash
npm run build
npm run preview
```
